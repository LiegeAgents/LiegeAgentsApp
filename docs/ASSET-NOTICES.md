# Reference assets

The reference homepage markup, compiled presentation CSS, fonts, logos, Rive files, photos, ribbon and dither rendering code were retrieved from the user-specified Mintlify website on 26 September 2026 for the requested faithful local recreation. Original rights remain with their respective owners. No license granting unrestricted redistribution was discovered. This private developer package does not represent a grant of font, trademark, image or code rights. Confirm production usage rights before public release.

Mintlify customer identity and testimonials are visibly presented only in the original-copy checkpoint. The Liege capability cards reuse the original ribbon/color-field images with opaque centered plates and new Liege glyphs covering the original customer marks. The Liege public-facing adaptation uses Liege identity and product examples. Existing `graphics/` and `graphics-v2/` through `graphics-v5/` folders were preserved. The user expressly selected the graphics-v5 half-solid / half-wireframe loop identity; its loop logo was made transparent with user-approved pixel unmatting and the matching 3:1 banner remains unchanged in public/brand/. These generated raster assets are not represented as original editable vector logos.

React, Vite, html-react-parser, Rive runtime and Lucide dependencies retain their upstream package licenses. The lockfile identifies the installed versions.

The official USDG token mark is preserved without recoloring or morphing; decorative motion is applied around it.
